Scope: only the excerpts in the supplied examples-alignment document were available. No `docs/PROJECT_WRITEUP.md` or client exists. The complete writeup, its other sections and an actual UI are **unverified**. This table exhausts the differences identifiable from those excerpts, not unseen requirements. All execution in this task used CPU and constructed mock data; NFHS-5 performance is unverified.
